# 地図

読む場面: 地図の上に要素を置く画面。条件がない原則はどこでも使い、条件がある原則は当てはまるときだけ使う。

## 原則

### 地図の端に近いラベルは、はみ出さない向きに出す〔必須〕
条件: 機能=地図 ／ 理由: 端で切れたラベルは読めず、何を指しているか分からなくなる。

### 地図上の要素を押したとき、広げる情報があれば1回目はその場で広げるだけにし、もう一度押したら関連する場所へ移動する〔推奨〕
条件: 機能=地図 ／ 理由: 1回目で画面が動くと地図上の位置を見失うため、確認と移動を分ける。

### 地図の初期表示の範囲は、表示するデータと利用者の作業に合わせ、点が重なって潰れる範囲を避ける〔推奨〕
条件: 機能=地図 ／ 理由: 全体表示のままだと密集した地域の点が潰れ、密集地だけに寄せるとほかの地点を見落とす(広く散らばるなら全体を表示し、近い点はまとめる)。
