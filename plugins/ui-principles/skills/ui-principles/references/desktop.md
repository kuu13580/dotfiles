# デスクトップ(広い幅)

読む場面: 広い幅。条件がない原則はどこでも使い、条件がある原則は当てはまるときだけ使う。

## 原則

### 広い幅のトップ画面では、一覧と主役の内容を分けて並べ、同時に見られるようにする〔推奨〕
条件: 幅=広い ／ 理由: 広い画面なら一覧と主役を同時に見せられ、画面を行き来する手間が減る。

### ポインタで操作する画面では、一覧などの各項目の頻度の低い操作をホバーやフォーカス時だけ出し、普段の画面を静かに保つ〔推奨〕
条件: 入力手段=ポインタ、機能=一覧 ／ 理由: 全項目に常に出すと騒がしい(タッチでは常時表示かメニューにし、重要・頻繁なものは隠さない)。

### 画面の性質に合わせてレイアウトを選び、内容を画面の幅に合わせて無制限に広げない〔推奨〕
条件: 幅=広い ／ 理由: 集中は単一カラム、多列データは全幅、確かめながらは2カラムが向き、広げすぎると右端を見落とす。
