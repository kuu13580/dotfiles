# AI機能

読む場面: AIによる生成・提案を含む画面。条件がない原則はどこでも使い、条件がある原則は当てはまるときだけ使う。

## 原則

### 有用なAIの支援は既定で先回りして出してよいが、すぐに退ける・オフにする・元に戻すことができるようにする〔推奨〕
条件: 機能=AI生成 ／ 理由: 自分で起動させる形では見落とされ、任せたくない人もいるため、すぐ退けて戻せる形にする。

### AIの処理中は、今何をしているかを段階的に見せる〔推奨〕
条件: 機能=AI生成 ／ 理由: 何も見えない待ちは長く止まったようにも感じ、作業が見えれば結果も信頼しやすい。
例: 「入力内容を読み込み中」のように作業を1行ずつ出し、終わったものに✓を付ける。

### AIの結果は全部そろうまで待たせず、できたものから順に出す〔推奨〕
条件: 機能=AI生成 ／ 理由: 早く最初の結果が見えると待ちが短く感じる(長さ不明の結果は下に足し、上をずらさない)。

### AIに補完させるときは、ユーザーが入力済みの値を書き換えず、空欄だけを埋める〔推奨〕
条件: 機能=AI生成 ／ 理由: 勝手に値が変わると入力が失われAIも信頼されない(書き換えを頼まれた場合は除く)。

### AIが入れた値には、ユーザーが入れた値と見分けられる目印を付ける〔推奨〕
条件: 機能=AI生成 ／ 理由: どれがAIの入れた値か分かれば、重点的に見直せる。
