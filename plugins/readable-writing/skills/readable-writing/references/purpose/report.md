# 把握してもらう文章

読む場面: 報告・進捗・調査結果・サマリなど、読み手に状況を把握してもらう文章を書くとき。`principles.md` に加えて使う。

## 層に置く塊の例

塊の役割の例で、この名前や順序を強制しない。該当しない塊は置かない。

| 層 | 塊の例 |
| --- | --- |
| 上の層 | 結論、次の対応(担当・期限)、影響 |
| 中段 | 原因と根拠、退けた仮説、後で知らせること |
| 下段 | 調査の経緯、計測データ、参照した資料 |

## 並び順は、読み手が最初に確かめたいことから決める

| 文書の種類 | 先に置くもの |
| --- | --- |
| 調査の報告 | 結論、次の対応、影響の大きさ |
| 障害の報告 | 影響と今の状況、暫定の対応、その後に原因と恒久の対策 |
| 進捗の報告 | 予定との差、遅れやリスク、その後に完了したこと |

## 原則

### 読み手がすべきことがないときも、「対応は不要」と書く
理由: 書かれていないと、読み手は自分に何か求められているのかを本文から探すことになる。

### 数値は、比べる相手と一緒に書く
理由: 数値だけでは、大きいのか小さいのか、良くなったのか悪くなったのかが分からない。
例: 「応答時間 2.4 秒」ではなく「応答時間(p95): 通常 300ms → 最大 2.4 秒」。

### 次の対応には、担当と期限を書く
理由: 担当と期限がないと、誰が動くのかが分からず、対応が止まる。
例: 対応・担当・期限を列にした表にする。決まっていない値は「未定」と書く。
