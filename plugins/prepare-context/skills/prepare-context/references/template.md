# 記録の雛形

## CONTEXT.md (注入対象・上限 400行 / 24KB)

```markdown
# CONTEXT.md — <タスクの一行説明> (<repo>/<key>)

## 確認した事実

| 事実 | 根拠 |
| --- | --- |
| <調査で確認した内容> | <ファイルパス:行番号 / URL / 実測値 / node ID> |

## 決定

| 論点 | 決定 | 理由 |
| --- | --- | --- |
| <何を決めたか> | <決定内容> | <1行> |

## 前提・保留事項

| 事項 | 状態 |
| --- | --- |
| <未確定のもの> | 仮置き / 要確認 / 未検討 |
```

根拠のない事実は書かない。前提が変わったとき、どの決定を見直すべきか辿れなくなる。

## CONTEXT.archive.md (注入しない・上限なし)

```markdown
# CONTEXT.archive.md — <repo>/<key>

## 撤回・変更された決定

| 論点 | 旧決定 | 新決定 | 変えた理由 |
| --- | --- | --- | --- |

## 詳細な根拠

<CONTEXT.md の表に収まらない実測値・ログ・引用>
```

CONTEXT.md が上限を超えたとき、および決定が変わったときに、ここへ移す (要約せず全文を移す)。
決定を見直す必要が出たときだけオンデマンドで読む。
